# Hierarchical Reinforcement Learning for Autonomous Drone Navigation

Welcome to the ultimate repository for my Final Year Project (FYP-II). This project demonstrates a robust, hierarchical Deep Reinforcement Learning (DRL) framework that enables an autonomous quadcopter to navigate highly complex, dynamic, and procedurally generated environments while actively rejecting extreme wind disturbances.

## 🚀 Key Features and Milestones

1. **Hierarchical Control Architecture:**
   - **High-Level Agent:** A highly trained Proximal Policy Optimization (PPO) neural network (via Stable-Baselines3).
   - **Low-Level Controller:** A highly tuned, deterministic PID controller that executes the target waypoints generated by the AI.

2. **Advanced Physics & Aerodynamics:**
   - **Aerodynamic Ground Effect (Downwash):** Custom PyBullet physics integration accurately simulating high-pressure air cushions when the drone flies under 0.5 meters.
   - **Dryden Wind Turbulence:** Real-time 240Hz spatial wind gusts actively push the drone off-course, forcing the AI to develop active disturbance rejection.

3. **State-of-the-Art Safety & Constraints:**
   - **Vortex Artificial Potential Fields (VAPF):** Real-time repulsive force vector generation to physically deflect the drone away from dynamic obstacles.
   - **Control Barrier Function (CBF):** A hard-coded mathematical safety shield guaranteeing the drone's collision avoidance constraints.
   - **Lipschitz Action Smoothing:** Constrains the rate-of-change in the neural network's outputs, preventing dangerous, erratic "jitter" commands and ensuring smooth, cinematic flight trajectories.

4. **Multi-Scenario Zero-Shot Generalization:**
   The AI was trained simultaneously on a procedurally generated `mixed` curriculum comprising:
   - 🏎️ **Racing:** Navigating through procedurally generated, suspended square gates.
   - 🌲 **Forest:** Dodging 15+ randomized dynamic and static tree trunks.
   - 🎯 **Target Tracking:** Continuously pursuing a moving Figure-8 target.
   - 🚧 **Slalom:** Maneuvering through shifting concrete pillars.

## 📊 Benchmark Results

After **1.5 Million Timesteps** of zero-shot training across all environments simultaneously:
- **Mixed Scenario Success Rate:** 60.0%
- **Condition:** High Dryden Wind Turbulence
- **Average Min Obstacle Distance:** 0.390 m
*(Achieving a 60% success rate on zero-shot randomized geometry under extreme wind represents a highly capable, generalized collision avoidance policy).*

## 💻 Running the Environments

You can evaluate the trained model in any scenario using the command line:

```bash
conda activate drone_fyp

# Run the Slalom scenario
python train/test_ppo.py --scenario slalom

# Run the Procedural Forest scenario
python train/test_ppo.py --scenario forest

# Run the Drone Racing scenario
python train/test_ppo.py --scenario racing

# Run the Dynamic Tracking scenario
python train/test_ppo.py --scenario tracking

# Run a random mixed evaluation
python train/test_ppo.py --scenario mixed
```

## 🧠 Training a New Model

To retrain the PPO model from scratch across all environments:

```bash
python train/train_ppo.py --scenario mixed --timesteps 2000000
```
